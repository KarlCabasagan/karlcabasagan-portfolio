# Workspace Agent Rules

## Mandatory Git Commit Directive
> **Commit every time there are changes no matter how small. The goal is to commit as much as possible.**

- After making any discrete file modification, feature addition, bug fix, or configuration update, stage and commit the changes immediately.
- Use clean Conventional Commits format (e.g. `feat: ...`, `fix: ...`, `docs: ...`, `style: ...`, `chore: ...`).
- Never leave modified working files uncommitted when moving between logical steps.

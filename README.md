# karlcabasagan-portfolio

Modern, multi-page creative developer portfolio for **John Karl Harley A. Cabasagan** (BSIT, Full-Stack Developer & Creative UI/UX Engineer).

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Routing:** React Router v7
- **Motion & Interactions:** Framer Motion
- **Icons:** Lucide React

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
